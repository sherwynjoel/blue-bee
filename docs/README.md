# docs/

Planning artifacts for Blue Bee. The PRD is the single source of truth.

| File | What it is |
|---|---|
| `laundry-platform-PRD.md` | **Canonical** build spec (v1.0, ~690 lines). Machine-readable; this is what the build follows. |
| `laundry-platform-PRD.docx` | Same content as the `.md`, formatted for humans. If the two ever differ, the `.md` wins. |
| `laundry-platform-blueprint.html` | Interactive visual blueprint (open in a browser) — surfaces, data model ERD, workflows. |
| `index.html` | Prior market-analysis dashboard that the strategy is built on. |

Codename note: the PRD uses the working codename **"Cascade"**; this project is named **Blue Bee**. Treat them as the same product.
