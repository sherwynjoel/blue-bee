## What shipped (all real, no stubs)
1. **In-house ETA behind the `EtaEstimator` seam** (`apps/api/src/tracking/`):
   - `eta-estimator.ts` — the swappable seam (`ETA_ESTIMATOR` token) + `EtaContext`/`EtaResult`.
   - `postgis-eta.estimator.ts` — `PostgisEtaEstimator` (the one real impl): remaining distance via the
     **same PostGIS `ST_Distance` geography** the sequencer uses, then the pure math. Bound in the
     module via `{ provide: ETA_ESTIMATOR, useExisting: PostgisEtaEstimator }`.
   - `eta-math.ts` — pure, unit-tested brain: haversine (for derived speed only), `deriveSpeedKmh`
     (path/time over the last N pings; null on stationary/first-ping/noise), `resolveSpeedKmh`
     (floor/ceil clamp; urban-average fallback), `computeEta` (distance×circuity÷speed; **EWMA against
     the aged prior target** so it shrinks without jitter; capped; range = mid ± pct).
   - `eta.service.ts` — resolves the vehicle's active stop (workable route + stop `EN_ROUTE`/`ARRIVED`,
     most-progressed), reads the `Site` geo destination, derives speed from recent pings, calls the
     estimator, **persists** `eta`/`eta_low`/`eta_high`/`eta_computed_at` (explicit `org_id`), emits `eta`.
2. **Geofence → durable row → emit** (`geofence.service.ts`): `APPROACHING` (distance ≤ radius OR ETA ≤
   threshold) + `ARRIVED` (tight radius), each **exactly once per stop** via `@@unique([route_stop_id,
   type])` + `INSERT … ON CONFLICT DO NOTHING`; emits only when a row was newly written. **Advisory** —
   no §5.4 stop transition.
3. **Realtime emit** (`realtime-publisher.service.ts`): `publishEta`/`publishGeofence` → the customer's
   **stop room** (stop-specific, so a co-routed customer on a different stop never sees this stop's ETA)
   + the **org fleet room**. New `eta`/`geofence` WS events defined in `packages/shared/src/tracking.ts`.
4. **Advance-hook orchestration** (`tracking-prediction.service.ts`): on a genuine CAS advance (the §10.4
   ping cluster), `IngestionService` awaits a degradation-wrapped recompute→geofence; a throw never fails
   `POST /locations:batch`.
5. **REST first-paint**: `GET /orders/:id/tracking` returns `stop.{eta,etaLow,etaHigh,etaComputedAt}`;
   `GET /fleet/live` returns each vehicle's `nextStopEta`.
6. **Config-driven** (`config/tracking.config.ts` + `.env`): `ETA_*` + `GEOFENCE_*` (circuity 1.3, urban
   30 km/h, floor/ceil 5/90, alpha 0.5, range 0.2, cap 14400 s, sample 5, min-move 15 m, throttle 0;
   approaching 800 m / 300 s, arrived 100 m) — no literals.
