## Deliberate, documented decisions
- **Motion = RN built-in `Animated`, not `react-native-reanimated`.** Honors the exact Daylight spring physics (stiffness 180 / damping 18), zero extra native deps, works in jest-expo + `expo export` on the flaky external drive. Centralized in `theme/motion.ts` — one-file swap to reanimated at the design-tokens merge if desired.
- **Icons = `@expo/vector-icons` (Feather + MaterialCommunityIcons `bee`)** — already hoisted at the workspace root (zero install risk).
- **No bottom-tab navigator.** The app is a single native-stack (the as-built contract + deep-link target); converting to tabs = navigation-contract change = Scope OUT. Premium chrome via themed large-title headers + the `Glass` surface (track chip/ETA card).
- **Track hero: no route line / destination dot.** `GET /orders/:id/tracking` returns only the vehicle last-known + the stop's ETA — no destination coordinate — so we never fabricate geometry. The map shows the real pulsing vehicle marker + the glass ETA card.
- **Primary CTAs (Approve / Pay / pay-cta) use azure** (the brief's primary-action color) — fixes white-on-green contrast and aligns with the system; success-green is reserved for state indicators.
