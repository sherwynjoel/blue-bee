## What this is
A pure visual/UX reskin of the Blue Bee operator console (`apps/web`, Next.js 14 App Router) to a premium, Apple-grade design system — **"Daylight"**. **No** changes to data fetching, `ConsoleApiClient`/`useAuthSession` calls, routes, business logic, RBAC, or component behavior. Every existing behavioral test still passes; markup invariants (text/testid/role/aria/label) were preserved character-for-character.

## The visual system applied (before → after)
- **Before:** a single brand-blue accent (`bb-blue #1f6feb`), flat GitHub-ish surfaces, one font, light-only, a top horizontal nav, ad-hoc per-screen status/empty/error styling, system-emoji icons.
- **After — Daylight:**
  - **Tokens** (in `apps/web/tailwind.config.ts` + `app/globals.css`, with a `.dark` variant): canvas/subtle/surface/hairline; ink/secondary/tertiary text; **azure primary** `#0B5FFF` (+hover/active/tint/fg); **honey** accent; success/warning/danger (+tints + tuned **AA "strong"** text tokens for badges-on-tints); elevation `e1/e2/e3`; focus ring; 8pt spacing; radii (card 16 / btn·input 12 / sheet 20 / pill); motion `120/200/320ms · cubic-bezier(.2,.8,.2,1)`.
  - **Dark mode**: a single `.dark` class re-themes everything via CSS variables. The legacy `bb-*` Tailwind tokens were **remapped onto the same variables**, so even untouched markup got the palette + dark parity for free; then every screen's hardcoded palette colors were migrated to semantic tokens. No-FOUC pre-paint init script + a persisted toggle (`lib/theme.ts`).
  - **Type:** Inter (UI) + JetBrains Mono (money/IDs/timestamps — `font-mono tabular-nums`) via `next/font`. Full type scale (display→caption) with tight title tracking.
  - **Icons:** `lucide-react` (one family, 1.5–2px, 18–24px). Added as a dependency (React-18 / SSR-safe).
  - **Primitives** (`components/ui.tsx`, back-compat APIs preserved): Button (primary/secondary/ghost/danger/destructive/success × sm/md/lg + loading + press-scale), Card, Input/Select/Textarea, Field (label/helper/error), Badge + **StatusPill** (dot + AA tone), **Skeleton/SkeletonText/TableSkeleton** (shimmer), EmptyState, ErrorBox (role=alert + retry), Loading, **Modal/Sheet** (scrim+blur+e3), **Tabs/SegmentedControl** (role=tab + aria-selected), **Table/Th/Td** (sticky hairline header, numeric right-align mono), **KV**, **Toast** provider, `cn()`.
  - **Signature `StatusTimeline`:** a vertical §5.1 stepper rendered from server state — filled "done" nodes, a pulsing "current" node, quiet "upcoming" — the hero of the order-detail screen.
  - **Shell:** grouped collapsible left sidebar (active = primary-tint pill, lucide icons) + a slim top bar (mobile menu + dark-mode toggle); account/sign-out in the sidebar footer. Restyled Login (ambient Daylight glow) + the no-access page; branded azure Logo + favicon.
  - **Fleet map:** theme-aware Leaflet — calm dark tiles (CSS filter), branded azure vehicle markers with a soft live-pulse, a frosted **glass** "live" status card; degrade-to-polling stays invisible.
  - **Every screen** gained: screen-shaped skeleton loaders, designed empty states, recoverable error states (retry), hover/press/focus states, list **stagger-in** motion, and dark parity. All reduced-motion-aware (global media query).

- **Accessibility posture:** AA contrast in both themes (badge text uses tuned `*-strong` tokens to pass on tints; data/primary/secondary text passes on canvas/surface); visible focus rings (global `:focus-visible` outline + `focus-visible:shadow-focus` on controls — see the login screenshot); all controls labelled (Field + preserved `aria-label`s); reduced-motion honored globally.
