## What shipped
The operator could already batch-invoice a B2B account (Track A) and split it by cost centre. This increment adds the **customer-facing portal** so the building's **account admin** can self-serve: view invoices + the cost-centre split, download a PDF statement, and pay — completing the B2B billing loop. Customer-facing + demoable to a condo/care-home client.

### API (`apps/api`, additive — no schema/migration)
- **Reads** — new `InvoicesModule`:
  - `GET /v1/invoices` — the caller's own account's invoices, cursor-paginated (number/status/issued/due/total).
  - `GET /v1/invoices/:id` — header + `InvoiceLine`s + the cost-centre split (`parseStoredBreakdown`).
  - Account confinement via `scopedPrisma` (Invoice is `ACCOUNT_DIRECT`): ACCOUNT_ADMIN/ACCOUNT_STAFF see ONLY their account; **cross-account/cross-org id → 404** (no existence leak). RBAC adds OWNER/FINANCE for support. Read-only, write-free, audit-free.
- **PDF statement** — `GET /v1/invoices/:id/statement.pdf` → `InvoicePdfService` (**`pdfkit`, pure-JS, no headless Chrome**) streams **real bytes** (`StreamableFile` + `application/pdf` + `Content-Disposition`/`Content-Length`): account/billing-terms header, line items, the cost-centre split, totals + HST, paid/due status. Account-scoped (404 out of scope).
- **Invoice-level pay** — `POST /v1/invoices/:id/payment-intent` (OWNER/ACCOUNT_ADMIN/ACCOUNT_STAFF, own account) on `PaymentService.createInvoiceIntent`:
  - Amount **server-computed from `invoice.total` incl. HST** (`payInvoiceSchema` carries only an optional note — no client money).
  - Reuses the proven `PaymentProvider` seam (`Stripe`/`Local`) + a **deterministic idempotency key** (`pi-invoice-<id>-<attempt>`); a **`SELECT … FOR UPDATE` row-lock** inside a `$transaction` serializes concurrent attempts so a race can't create two PENDING payments / two Stripe intents (no double-charge). Returns the **`client_secret` only** (PCI SAQ-A).
  - 403 cross-account (same org) / 404 cross-org via `requireInvoiceForPay`.
  - `GET /v1/invoices/:id/payment` (scoped) for polling.
- **Webhook is the source of truth** — the invoice flips **PAID only inside the signature-verified `payment_intent.succeeded` tx** (`applyPaymentSucceeded`, in-tx flip pinned by `orgId`), with an **underpayment guard** (captured < the requested total ⇒ the payment is SUCCEEDED but the invoice is NOT marked PAID + an audited `INVOICE_PAYMENT_UNDERPAID` anomaly). Forged/unsigned → **400**; redelivery a no-op (`ProcessedStripeEvent` claim). The receipt reuses the Inc-8 notification engine via a new account-scoped recipient resolver (`resolveAccountRecipients`).
- **Provider seam** — `CreateIntentInput.orderId` is now optional + an `invoiceId` was added; `Stripe`/`Local` providers set metadata conditionally. **The order-level pay/receipt/refund/dispute path is behaviorally unchanged** (the new `if (payment.invoiceId)` block is a no-op for order pays; order metadata still carries `orderId`).

### Web (`apps/web`, Daylight, Next 14 / React 18.2)
- New **`(portal)` route group** + `PortalShell` (slim top bar, no ops sidebar). `AppShell` + the root route (`app/page.tsx`) route an ACCOUNT_ADMIN/ACCOUNT_STAFF token to **`/portal`** (not the ops console, not no-access) via a jsdom-safe redirect; `lib/rbac.ts` gained `PORTAL_ROLES`/`isPortal`/`can.portal`.
- **my-invoices** list → **invoice detail** (lines + a cost-centre split table reconciling to the total + Download-PDF + Pay) → **pay on web** → **receipt**. Honest skeleton/empty/error states, dark parity, tabular money.
- **Pay surface** — `@stripe/stripe-js` + `@stripe/react-stripe-js` **PaymentElement**, loaded **SSR-safe** via `dynamic(ssr:false)` (mirrors the Leaflet pattern). The card never touches our API — only the `client_secret` crosses; on confirm we **poll `GET /v1/invoices/:id` until the webhook flips PAID** (REST-is-truth). When no Stripe test-mode publishable key (or a local `pi_local` secret) is present it renders an **honest note** ("card entry requires a Stripe test-mode key; the webhook confirms PAID") + a Refresh-status button — **never a faked charge**.
- Typed `ConsoleApiClient` methods: `listInvoices`, `getInvoiceById`, `payInvoice` (idempotency-key arg), `downloadInvoiceStatement` (bearer blob).
- Shared a11y win: the design-system `Modal`/`Sheet` gained focus management (autofocus + Escape + Tab focus-trap + focus restore).
