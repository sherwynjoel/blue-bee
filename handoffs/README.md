# handoffs/

Saved context handoffs for Blue Bee — one file per chat handoff, so project context is never lost in chat.

**Resume in a new chat:** mount `/Volumes/Gowtham`, read the newest dated file here, then check `../CHANGELOG.md` for any builds since.

**Naming:** `YYYY-MM-DD-handoff.md` (add `-HHMM` if more than one in a day). Newest date = latest state.
